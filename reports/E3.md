## Flash command (DO NOT RUN without Pavan's approval)
App-only, preserves NVS (touch record). Release/pause the hub first so it does not hold the port. Port seen by device.md: /dev/cu.usbmodem1101.
    source /Users/4625labs/Workspace/cyberdefence-hackathon/toolchain/env.sh
    esptool --port /dev/cu.usbmodem1101 write-flash 0x10000 /Users/4625labs/Workspace/cyberdefence-hackathon/target/agent-dial/firmware/.build/agent_dial.ino.bin
Valid only if the board already carries app3M_fat9M_16MB (app at 0x10000); device.md infers this but it is UNVERIFIED. A factory-table board needs a merged image at 0x0 (fresh install, erases NVS; back up flash first). Back up first anyway: `esptool --port ... read-flash 0 0x1000000 backup.bin`.

## Host tests (ran, passed)
- test_frame.cpp vs tests/vectors/dial_frame.txt, vector mode (-DDIAL_MAX_PAYLOAD=8192): `PASS: 55 checks, 0 failures`
- same, firmware cap (default 2039): `PASS: 60 checks, 0 failures` (incl. a hand-built, correctly CRC'd 2048-byte frame is rejected; encoder refuses 2040+ payload; length 0xFFFF and cap+1 resync)
- fuzz_frame.cpp, 20000 random streams under ASan+UBSan: `fuzz ok: frames=5579 max_payload_seen=2037 cap=2039`, rc=0.
Deviation from SPEC: the wire limit is 8192 but firmware caps at payload 2039 (whole frame < 2048) per the task; the hub already trims to < 2048 (SPEC Limits). Any E2 hub frame >= 2048 bytes is silently resynced away by the device.

## Strict input handling (the point of this project)
Frame: fixed buffers sized to the cap, length checked before use, CRC, resync, no heap per frame. JSON: payload must be 2..2039 bytes, no NUL bytes, ArduinoJson nesting limit 6, must be an object with string `t` of 1..24 chars. Per message: session id must be printable ASCII 1..47 (else rejected), key/requestId printable ASCII 1..79, counts capped (16 sessions, 4 questions, 6 options, 8 caps), wrong types reject the whole message, unknown session ids ignored, all display strings sanitized (control chars dropped, malformed UTF-8 and non-Latin codepoints -> '?', truncated by codepoint). Counters bad_frames/bad_json/unknown_t exposed in diag.state and AD_STACK log. Strings never printf'd as format strings.

## What the MVP covers vs SPEC
Covered (compiled, not device-tested):
1. Boot to Overview (count, "All idle"/"N working", 3 buttons drawn).
2. Hub link: A5 45 frames, hello every 2 s (15 s when connected), welcome -> connected + `agents.list`, ping/pong, 15 s silence -> clear to "Not connected", LOG frames after welcome (AD_STACK, AD_SOUND, AD_EVENT), plain console before.
3. agents.begin/agent/agents.end, focus, turn.started/done/error (rotating verb + elapsed, activity line), summary (recap card, beep, drawer row, quiet), question (single/multi + Done, multiple questions sequentially, approval Allow/Deny), question.close, notif.seen, toast, voice.error.
4. Outbound: `answer {id,requestId,answers{key:string}}` (multi joined ", "), `turn.stop`, `focus`, `agent.open {reason:"question"}`, `agents.list`, `pong`, `hello`.
5. Buttons: BtnA left, BtnB right, both = select, both 600 ms = back (c25k ButtonGrammar, copied). Left/right page sessions or move option focus; select answers; back dismisses question / asks "Cancel task?" (only with `stop` cap, else toast "Can't stop this from here") / closes drawer. MVP addition: Enter on a tile with an open question reopens it (needed because there is no other button path).
6. Touch through the shared espt-touch record (v1 and v2, full warp). Tap options/rows/chevrons, swipe left/right pages, swipe down from top = drawer, swipe up from bottom toggles tile/overview. If no valid record exists it falls back to M5GFX converted points (UNVERIFIED, flagged).
7. Drawer (rows, open, close), toasts 2.2 s, beep (3 x 2 kHz, 80 ms, max 1/s), 5 min sleep, waking input swallowed, 16 KB loop stack (SET_LOOP_TASK_STACK_SIZE), all timers via signed `since()` against fresh millis(), Serial TX timeout 0.
8. diag.state and diag.act (left/right/enter/back/swipe_down_top/confirm_yes/confirm_no) minimal; not the full contract state shape, so tests/check_device.py will NOT pass unmodified.

NOT done (spec gaps): LVGL 9.5.0 + Geist fonts + upstream icons (drawn with M5GFX DejaVu fonts, so visuals differ from the reference screens; LVGL compile itself still UNVERIFIED), voice overlay/mic/PCM/STT, Settings screen and the touch calibration flow, Wi-Fi/mDNS/HTTP direct mode, USB pairing/wifi provisioning (pair/wifi/forget messages are logged and ignored), notif.replace, SHOT/diag.shot framebuffer dump, full AD_* evidence set (only AD_HARDWARE, AD_TOUCHMAP, AD_SCREEN boot, AD_SOUND, AD_EVENT, AD_STACK), full diag.act contract, 16 verbs rotate at 6 s but are not compared to upstream, brightness setting.
