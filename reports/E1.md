## Gotcha: ctags
Bundled ctags is x86_64 and this Mac has no Rosetta ("bad CPU type"). I moved it to toolchain/data/packages/builtin/tools/ctags/5.8-arduino11/ctags.x86_64.orig and replaced `ctags` with a stub (`exit 0`). Consequence: arduino-cli will NOT auto-generate function prototypes for .ino files. Declare functions before use or write the firmware as a .cpp/.h-style sketch (Day 35 passes -DLV_CONF_INCLUDE_SIMPLE -I<sketch> via build.extra_flags / --build-property). Reinstalling the core/builtin tools would overwrite the stub.
