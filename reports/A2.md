# A2: Akash scanner (untrusted scanner on a rented machine, no secrets)

Files (all in cairn/akash/scanner/): deploy.yaml (SDL, 5.7 KB), build_sdl.py (regenerates it), run.sh (the container job), local_check.sh, ingest_logs.py, CHECKLIST.md, sample-fake-logs.txt.
Nothing was sent to Akash; no sign-in, no lease.

## Design
- Image `semgrep/semgrep:1.180.0` (public). `command: [sh, -c]`, args = one line: decode tar.gz of cairn/rules/*.yml (base64) and run.sh (base64), then `CLONE_URL=https://github.com/chantastic/esptember.git sh run.sh`.
- esptember origin is `https://github.com/chantastic/esptember.git` (read-only `git remote -v`). Confirmed public: anonymous `git ls-remote` and `git clone --depth 1` worked; HEAD 2ea26363 equals the local HEAD, and all 13 scanned seed files are byte-identical to target/seeds (so no base64 fallback of seeds needed).
- SDL: version 2.0, 0.5 cpu, 512Mi, 1Gi storage, `denom: uact`, amount 100 (per sponsors.md; denom/units UNVERIFIED, docs page fetched only had the quick-start example). No expose (nothing public); UNVERIFIED that Akash accepts a service without expose, fallback in CHECKLIST. No env vars, no secrets.
- Output: `CAIRN-INFO cloned ... @ sha`, `CAIRN-SCAN-BEGIN akash-esptember`, JSON lines {card, file, line, rule_id, seed_shape, severity, snippet}, `CAIRN-SCAN-END`, `CAIRN-SUMMARY ...`, then `sleep 1800`. After sleeping the container exits and Akash will restart it (repeat scan); ingest takes the first block. Must be closed by Pavan.
- Snippets are read from the file by run.sh because offline Semgrep OSS does not return matched lines.

## ingest_logs.py
`python3 cairn/akash/scanner/ingest_logs.py LOGFILE | python3 events/cairn_log.py append`. Strict allow-list validation (exact field set, types, card must be known, rule_id regex tied to card, file path regex with no `..`, snippet <= 200 with no control chars); any bad row aborts with exit 2 and no output. Tolerates log line prefixes; first block only unless --all; dedupes. Kind is `finding` only for a seed_shape hit in the card's seed file (same rule as cairn/sweep), else `cousin_candidate`; actor akash-scanner, tool semgrep, verdict unconfirmed, repo esptember.
Test on fake log (prefixed lines + a duplicated restart block, sim built from the real run): `ingest_logs: 50 events (2 finding, 48 cousin_candidate) from 2 block(s)`, then `cairn_log.py --db <scratch> append` returned `appended 50 event(s)`. Negative test (`"file":"../etc/passwd"`): `REJECT (file path)`, rc=2. The 2 findings are day-03 idf_component.yml:3 and portal.c:113, matching E4.
