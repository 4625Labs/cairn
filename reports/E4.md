# E4: cairn sweep (seed -> cousins)

## Semgrep
`uvx semgrep --version` works: **1.180.0** (no system install; uvx cache). Docker also exists but was not needed.
Command used by the sweep: `uvx semgrep --config cairn/rules --metrics=off --json --quiet --no-git-ignore .` (override with `$SEMGREP`).

## Files
- `cairn/rules/unvalidated-network-input.yml`, `cairn/rules/unpinned-dependency.yml`: every rule has `metadata.card`; seed-shaped rules also have `seed_shape: true`.
- `cairn/sweep`: Python 3, stdlib only. Run: `cairn/sweep [--target DIR] [--out FILE] [--repo NAME] [--include-reference]`.
  JSONL to stdout (or --out), human summary to stderr. Fields: ts, kind, card_id, repo, file (relative to target), line, snippet, rule_id, verdict:"unconfirmed".
  Seed = a `seed_shape` rule hit in the card's seed file (read from card front matter), so it survives line shifts. Everything else is `cousin_candidate`. `*.fixed.*` files are skipped by default (reference copies).
- `cairn/out/sweep-seeds.jsonl`: output of the default run (49 rows).

## Honest limits: where Semgrep did not do the job
- **YAML/JSON/lockfiles**: used Semgrep `generic` language with `pattern-regex` (the structured YAML/JSON patterns were not tried for lack of time). Regex, not parsing.
- **`.ino`**: Semgrep has no language for it. A Python regex fallback in `cairn/sweep` (`fallback-ino-atoi`, `fallback-ino-sscanf`) flags every `atoi(`/`sscanf(` line. It is noisy by design (no range-check analysis).
- **C**: Semgrep parsed portal.c with a partial-parse warning (`AP_IP` macro at line 168); the matches we need still fire. `.h` files parse as C.
- **C rules are shape matches**: `atoi(...)` flags every call; `strtol($H,NULL,16)` flags any such call. No dataflow from radio/socket to the call. The HTML rule skips calls whose argument name contains esc/safe/html (a heuristic, which is what removes the portal.fixed.c false positive).
- **JS**: real taint rule (JSON.parse -> path.basename / shortId).
