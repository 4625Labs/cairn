Run (project root):
- `source cairn/env-clickhouse.sh && python3 cairn/cards/cards_sync.py sync`   (idempotent: new version only if file sha256 differs from latest stored)
- `python3 cairn/cards/cards_sync.py list` / `show <card_id>`
- SQLite fallback: `python3 cairn/cards/cards_sync.py --sqlite events/cards.db sync|list|show`
