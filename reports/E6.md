# E6: fix-and-gate pipeline (cairn/fix)

## Files
- `cairn/fix/run.py` (Python stdlib; calls cairn/sweep, cairn/ingest, events/cairn_log.py, `cc`, `patch`, target/agent-dial/host)
- `cairn/fix/test_html_escape.c` (32 checks; the helper is extracted from the PATCHED portal.c and included, so it tests the shipped code; built with ASan+UBSan)

Exit codes: 0 approved and files written, 2 gate refused, 3 human denied, 4 dial error.
`--sim` starts a hub (AGENT_DIAL_PORT=sim, AGENT_DIAL_HOME in a temp dir under cairn/out) plus `agent-dial sim --auto allow|deny`, then runs `agent-dial ask --approve`. Without `--sim` it calls the real client (hub/device), timeout 120 s.

## What the patch does
- portal.c: adds `html_escape()` after `submit_cb`, applies it to each SSID (`escaped[200]` buffer, 32 SSID bytes at most 192 escaped) before `<option>%s</option>`. Real unified diff (difflib, a/ b/ paths, applied with `patch -p1`). Written by me; portal.fixed.c was not copied.
- Dependency: day-01 `waveshare/esp32_s3_touch_amoled_1_8: "^2.0.3"` -> `"==2.0.3"`, the pin day-03 already uses. Note: the tca9554 `"*"` seed has NO concrete version in any neighbouring manifest (checked), so I did not invent one; the unpinned-dependency seed (day-03 line 3) stays, and the pipeline only requires the portal seed gone.
- Re-scan comparison is by (rule, file, snippet) so line shifts are not "new" findings.

## Verify mode (for the Guild PR, which cannot call local code)
    python3 cairn/fix/run.py verify --patch /path/to/branch.patch --sim
    python3 cairn/fix/run.py verify --patch /path/to/fetched-branch-dir --sim
Pavan fetches the branch/patch himself; this mode does no git or network. It resets `target/work-verify/` from target/seeds, sweeps (logs findings), applies the patch (`patch -p1`, falls back to -p0; a directory is overlaid onto the seeds copy, `.git` skipped, only files that already exist in seeds, and a diff is derived), re-sweeps, runs the C test, logs agent_write (actor guild-fixer), pr_gate, asks the dial, logs device_approval, and on approval writes cairn/out/pr/. Tested: good patch + Allow -> exit 0 and files written; sabotaged patch -> BLOCK exit 2; directory + Deny -> exit 3.
Limit: the unit test requires a function named `static void html_escape(const char*, size_t, char*, size_t)` in portal.c; a differently named or shaped helper fails the test (fails closed). Test input for the hosted agent: tell it to use that signature.
Not cross-checked: the `cairn-fix-result` JSON block is not parsed.
